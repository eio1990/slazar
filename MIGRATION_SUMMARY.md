## Обзор

Выполнена комплексная миграция базы данных для очистки и оптимизации номенклатуры продуктов согласно финальному утвержденному списку пользователя.

## Важные замечания

### Особые случаи

1. **"Курка філе" (ID 6) → "Курка вагова" (ID 227)**
   - ID 6 - это сырье, не может быть источником для фасовки
   - Создан ID 227 для весового продукта после производства
   - packaging_recipes обновлены

2. **Дубликаты "вагова/ваговий" (ID 175, 176, 177, 179, 184)**
   - НЕ удалены, так как используются в активных packaging_recipes
   - Это packaging SKU, а не production outputs
   - Требуют дальнейшего анализа для возможного объединения

3. **ID 106 "Індичка сиров'ялена"**
   - Используется как target в recipe
   - Используется как source в 4 packaging_recipes
   - Не заменен на ID 233, так как это разные стадии
