## 🎯 Огляд

Комплексна система для управління всім циклом виробництва м'ясної продукції:

```
СИРОВИНА → РОЗДІЛКА → ВИРОБНИЦТВО → ФАСУВАННЯ → ГОТОВА ПРОДУКЦІЯ
```

### Основні можливості:

- ✅ **Облік сировини** - приход та видача м'яса різних категорій
- ✅ **Розділка туш** - обробка туш на напівфабрикати
- ✅ **Виробництво** - створення готової продукції за рецептами
- ✅ **Фасування** - упаковка в SKU (вакуум, скін, вагова)
- ✅ **Складський облік** - залишки, історія, фільтри
- ✅ **Офлайн режим** - робота без інтернету з синхронізацією

## 📦 Модулі системи

### 1. 🔧 Операції (Operations)
Базові складські операції з матеріалами та сировиною.

**Функції:**
- Прихід товару на склад (з ціною)
- Видача зі складу (з контролем залишків)
- Фільтрація за категоріями (М'ясо, Спеції, Матеріали)
- Пошук по номенклатурі
- Примітки до операцій

### 2. 🔪 Розділка (Butchery)
Перша стадія виробництва - обробка туш.

**Процес:**
1. Вибір рецепту розділки (яловичина/конина)
2. Введення ваги вхідної сировини
3. Автоматичний розрахунок очікуваного виходу
4. Введення фактичних ваг кожного виду напівфабрикату
5. Облік відходів та стеку (не йдуть в залишки)

**Приклад:**
```
Яловичина туша (100 кг) → 
  - Яловичина для бастурми (45 кг)
  - Яловичина для суджука (30 кг)
  - Яловичина для пластин (15 кг)
  - Жир яловичий (5 кг)
  - Кістки, Стек (5 кг, відходи)
```

### 3. 🥓 Виробництво (Production)
Виробництво готової продукції за рецептами.

**Етапи:**
1. **Створення партії** - вибір рецепту, введення ваги
2. **Засолка** (salt) - додавання солі та води
3. **Замішування** (mix) - автоматичне списання спецій зі складу
4. **Набивка** (stuff) - облік оболонок (зважування до/після)
5. **Сушіння** (dry) - виставлення дати готовності
6. **Завершення** - розрахунок виходу та оприбуткування

**Рецепти:**
- Бастурма класична
- Конина (бастурма з конини)
- Суджук
- Махан
- Курка сиров'ялена
- Індичка
- Пластини (яловичина/конина)
- Банкетна (свинина)

### 4. 📦 Фасування (Packaging)
Упаковка готової продукції в SKU для продажу.

**Концепція сесій:**
- Одна сесія = один джерельний продукт (вагова продукція)
- В одній сесії можна упакувати в різні SKU
- Автоматичний розрахунок матеріалів (пакети, етикетки)
- Облік браку матеріалів
- Облік залишків (опала спеція)
- Облік втрат (waste)

**Приклад:**
```
Сесія PKG-22112025-001
Джерело: Бастурма вагова (10 кг)

Вихід:
  - Бастурма 50г вакуум × 100 шт = 5 кг
  - Бастурма 60г скін × 50 шт = 3 кг
  
Залишки:
  - Бастурма вагова 1.5 кг (опала спеція)
  
Втрати: 0.5 кг
```

### 5. 📊 Склад (Stock)
Перегляд залишків та історії руху.

**Можливості:**
- Залишки всієї номенклатури
- Фільтри за категоріями
- Фільтри за типами м'яса
- Статистика використання
- Швидкий пошук

### 6. 📜 Історія (History)
Журнал всіх операцій.

**Фільтри:**
- За типом (Прихід/Розхід/Виробництво)
- За періодом
- За номенклатурою

## 🚀 Запуск

### Backend

```bash
# Встановлення залежностей
cd /app/backend
pip install -r requirements.txt

# Встановлення ODBC Driver
apt-get install -y unixodbc msodbcsql18

# Запуск
uvicorn server:app --host 0.0.0.0 --port 8001 --reload
```

### Frontend

```bash
# Встановлення залежностей
cd /app/frontend
yarn install

# Запуск
expo start --tunnel
```

### Сервіси (Docker)

```bash
# Перезапуск всіх сервісів
sudo supervisorctl restart all

# Окремо backend
sudo supervisorctl restart backend

# Окремо frontend
sudo supervisorctl restart expo
```
