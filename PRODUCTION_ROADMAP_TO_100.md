## ❌ ЩО НЕ РЕАЛІЗОВАНО (10% до 100%)

### 🔴 КРИТИЧНІ НЕДОЛІКИ:

#### 1. **Відсутні UI форми для кроків виробництва**

**Проблема:** Є лише 3 форми (mix, salting, stuffing), але немає для:
- ❌ Обрізка (trim) - введення ваги обрізок
- ❌ Цукрування (sugar) - endpoint є, форми немає
- ❌ Масаж з водою (massage) - endpoint є, форми немає
- ❌ Промивка, сушка, прес - загальні кроки без спецформ
- ❌ Виготовлення маринаду (відрізняється від чаману)

**Наслідок:** Оператор не може пройти повний цикл виробництва через UI

**Складність:** Середня (6-8 годин)

---

#### 2. **Відсутність валідації виходу продукції**

**Проблема:** При завершенні партії немає перевірки:
- ❌ Вихід < expected_yield_min → вимога коментаря
- ❌ Вихід > expected_yield_max → попередження про аномалію
- ❌ Немає розрахунку % втрат

**Приклад:** Для Бастурми очікується 60-65%, якщо вийде 40% - система промовчить

**Складність:** Низька (2-3 години)

---

#### 3. **Відсутня валідація використання готового чаману**

**Проблема:** 
- ❌ Якщо на складі є готовий чаман, але оператор виробляє новий - система не попереджає
- ❌ Немає підказки "На складі є 5 кг готового чаману. Використати?"

**Складність:** Низька (2 години)

**Наслідок:** Втрачається контроль над обрізками (можуть використовуватися для Суджука)

def check_anomalies(operation_type, actual_value, expected_value):
    """Перевірка на аномалії"""
    deviation = abs(actual_value - expected_value) / expected_value * 100
    
    if deviation > 50:  # Відхилення > 50%
        return {
            "warning": f"Відхилення {deviation:.1f}% від норми. Перевірте дані.",
