# Інструкція по тестуванню SLAZAR на планшеті

## Огляд

Це інструкція для E2E тестування застосунку безпосередньо на Android планшеті з реальною базою даних. Без використання Expo Go - збираємо нативний APK і встановлюємо на пристрій.

## Передумови

### На комп'ютері розробки:
- Node.js 16+ встановлено
- Python 3.11+ встановлено
- Android Studio встановлено (для Android SDK)
- Java JDK 17 (входить в Android Studio)

### На планшеті:
- Android 5.0+ (API level 21+)
- Дозволено встановлення з невідомих джерел (Settings → Security → Unknown sources)

### База даних:
- MS SQL Server 2022 на 85.238.112.232:14330
- База: SLAZAR_DB
- Доступ налаштовано через .env файл

## Крок 1: Підготовка середовища

### 1.1. Налаштування Android SDK

```bash
# Перевірте, що ANDROID_HOME налаштовано
echo $ANDROID_HOME  # або echo %ANDROID_HOME% на Windows

# Якщо не налаштовано, додайте в системні змінні:
# Windows: C:\Users\YourName\AppData\Local\Android\Sdk
# macOS/Linux: ~/Android/Sdk
```

### 1.2. Перевірка залежностей backend

```bash
cd backend

# Перевірте, що всі залежності встановлені
pip install -r requirements.txt
```

### 1.3. Перевірка залежностей frontend

```bash
cd frontend

# Встановіть залежності якщо ще не встановлені
npm install
# або
yarn install
```

## Крок 2: Налаштування .env файлів

### Backend (.env в папці backend/) ✅

Ви вже створили цей файл:

```env

MSSQL_DATABASE=SLAZAR_DB
MSSQL_USER=llm_user

# API Configuration
API_HOST=0.0.0.0

```

### Frontend (.env в папці frontend/) 📝

**Ви маєте 3 варіанти налаштування:**

#### Варіант 1: Backend на вашому комп'ютері (потрібна та ж Wi-Fi мережа)

```env
# Backend API URL - ваш локальний комп'ютер
EXPO_PUBLIC_BACKEND_URL=http://10.100.0.60:8001
```

**Переваги**: Швидко, зручно для розробки
**Мінуси**: Планшет має бути в тій же мережі (tenet.local)

---

#### Варіант 2: Підключення напряму до production сервера ⭐ РЕКОМЕНДОВАНО

```env
# Backend API URL - production сервер
EXPO_PUBLIC_BACKEND_URL=http://85.238.112.232:8001
```

**Переваги**:
- ✅ Не потрібна та ж Wi-Fi мережа
- ✅ Працює звідки завгодно (будь-який інтернет)
- ✅ Тестуєте на реальній БД

**Мінуси**:
- ⚠️ Backend має бути запущено на сервері 85.238.112.232
- ⚠️ Порт 8001 має бути відкрито на сервері

**Для цього варіанту потрібно:**
1. Запустити backend на сервері 85.238.112.232
2. Відкрити порт 8001 в firewall сервера
3. Або налаштувати тунель/проксі

---

#### Варіант 3: Standalone режим (без зовнішнього backend)

```env
# Вбудований backend в APK
# EXPO_PUBLIC_BACKEND_URL не потрібен
```

**Потребує модифікації**: Додати SQLite в застосунок замість MS SQL

---

**Який варіант обрати?**

Для вашого сценарію **рекомендую Варіант 2**, але для цього потрібно:
- Або запустити backend на production сервері
- Або налаштувати тунель (ngrok, cloudflare tunnel) з вашого локального backend

## Крок 3: Запуск Backend

### Варіант А: Локальний backend (для Варіанта 1 з тією ж мережею)

```bash
cd backend

# Запустіть сервер
python -m uvicorn main:app --host 0.0.0.0 --port 8001 --reload

# Ви повинні побачити:
# INFO:     Uvicorn running on http://0.0.0.0:8001
# INFO:     Application startup complete.
```

Залишіть цей термінал відкритим - сервер має працювати під час тестування.

### Варіант Б: Локальний backend з тунелем (для тестування з будь-якої мережі) ⭐

**Використовуйте ngrok для створення публічного URL:**

1. **Встановіть ngrok:**
   - Завантажте з https://ngrok.com/download
   - Або через Chocolatey: `choco install ngrok`

2. **Запустіть backend:**
   ```bash
   cd backend
   python -m uvicorn main:app --host 0.0.0.0 --port 8001 --reload
   ```

3. **В іншому терміналі запустіть ngrok:**
   ```bash
   ngrok http 8001
   ```

4. **Скопіюйте публічний URL:**
   ```
   Forwarding  https://abc123.ngrok.io -> http://localhost:8001
   ```

5. **Оновіть frontend/.env:**
   ```env
   EXPO_PUBLIC_BACKEND_URL=https://abc123.ngrok.io
   ```

**Переваги ngrok:**
- ✅ Не потрібна та ж Wi-Fi мережа
- ✅ HTTPS з коробки
- ✅ Працює звідки завгодно
- ✅ Безкоштовний для розробки

**Мінуси:**
- ⚠️ URL змінюється при кожному перезапуску (в безкоштовній версії)
- ⚠️ Потрібно оновлювати .env при зміні URL

### Перевірка backend:

Відкрийте в браузері:
- Локальний: `http://localhost:8001/docs`
- Ngrok: `https://abc123.ngrok.io/docs` (замініть на ваш URL)

Ви повинні побачити Swagger документацію API.

## Крок 4: Збірка і встановлення APK на планшет

### Варіант А: Збірка development APK (рекомендовано для тестування)

```bash
cd frontend

# Перша збірка (займе 10-15 хвилин)
npx expo run:android

# Це автоматично:
# 1. Збере APK
# 2. Встановить на під'єднаний пристрій через ADB
# 3. Запустить застосунок
```

**Важливо**: Під'єднайте планшет до комп'ютера через USB або увімкніть wireless debugging.

### Варіант Б: Збірка APK файлу для ручного встановлення

```bash
cd frontend

# Збірка APK
npx expo run:android --variant release

# APK буде в:
# frontend/android/app/build/outputs/apk/release/app-release.apk
```

Потім перенесіть APK на планшет через:
- USB кабель
- Email
- Google Drive
- Airdroid
- Будь-який файловий менеджер

### Перевірка ADB connection (якщо планшет під'єднано через USB):

```bash
# Перевірте підключені пристрої
adb devices

# Ви повинні побачити щось на кшталт:
# List of devices attached
# ABCD1234    device
```

## Крок 5: Налаштування планшета

### 5.1. Увімкнути Developer Options:
1. Налаштування → Про планшет
2. Натисніть "Номер збірки" 7 разів
3. Developer options з'являться в налаштуваннях

### 5.2. Увімкнути USB Debugging:
1. Налаштування → Developer Options
2. Увімкніть "USB Debugging"

### 5.3. Дозволити встановлення з невідомих джерел:
1. Налаштування → Безпека
2. Увімкніть "Невідомі джерела" (або для конкретного файлового менеджера)

## Типові проблеми

### Планшет не може під'єднатися до backend

**Проблема**: Помилка "Network request failed"

**Рішення**:
1. Перевірте, що backend запущено: `http://YOUR_LOCAL_IP:8001/docs`
2. Перевірте, що планшет і комп'ютер в одній мережі Wi-Fi
3. Перевірте firewall - дозвольте порт 8001
4. Перевірте EXPO_PUBLIC_BACKEND_URL в .env - має бути локальна IP, не localhost

### Помилка збірки "SDK location not found"

**Рішення**:
```bash
cd frontend/android
echo "sdk.dir=C:\\Users\\Ihor\\AppData\\Local\\Android\\Sdk" > local.properties
```

### Metro Bundler помилка

**Рішення**:
```bash
cd frontend
rm -rf node_modules
npm install
npx expo start --clear
```
