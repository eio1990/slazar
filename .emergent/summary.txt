<product_requirements>
The application is a comprehensive warehouse and production management system for a meat processing facility. Its purpose is to digitize and track the entire production lifecycle, from raw material intake to finished goods.

A recent major change in business requirements has split the production process into two distinct modules:
1.  **Butchery Module (New Requirement):** This module manages the breakdown of raw carcasses (e.g., beef, horse) into various primal cuts and by-products (e.g., Яловичина на бастурму, перший сорт, жир, кістки). It must also account for non-inventory yield loss like стек (blood and water runoff) for costing purposes.
2.  **Production Module (Existing, to be refactored):** This module consumes the primal cuts produced by the Butchery module to create finished products like Бастурма and Суджук. The original logic of consuming carcasses directly is now obsolete.

Other implemented modules include a partially built Packaging module for packing finished goods and a basic Inventory module for stock adjustments. The system must enforce business rules like preventing negative stock balances and using idempotency keys for all operations.
</product_requirements>
